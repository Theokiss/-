基于零宽字符与本地加密的 DOCX 防二次传播溯源系统，一人一密，五重证据链。
防二传版权溯源系统：一套基于零宽字符隐写与本地 AES-256-GCM 加密的 DOCX 文档防二次传播方案。核心思路是「一人一密、一人一水印」——作者上传文档后本地加密，云端只托管密钥；读者通过 QQ 邮箱验证码验证身份后，在浏览器本地解密并注入专属隐形水印，下载到一份「只有他自己有」的版本。一旦文档外流，溯源端可从 docx/zip 中通过五重检测（分发追踪文件、作者归属文件、零宽水印、自定义属性、ZIP 多文档遍历）反向查出泄露者 QQ，并输出完整证据链。水印不可见、可冗余、可恢复，正文、页眉、页脚、脚注、批注、自定义属性等多个角落反复埋点，删掉一部分还剩一部分。文档内容全程不出本机，服务器只见密钥不见文档，即使被拖库也无法直接解密。
本项目给「小手机AI」的作者/产饭作者整理，供学习、参考与二次开发使用。
